## 제목
- 키워드를 앞쪽에 배치
- 40~60자, 정보성 + 궁금증 ("꼭 확인", "뜻", "비교", "하는 법", "TOP3")
- 낚시 과다 금지, 검색 의도 충족형

## 구조
1. 후킹 도입 2~3문단 (문제 상황/의심)
2. 번호형 소제목 5~7개 (1. 2. 3. ...)
3. 각 섹션 장문 2~4문단 + 핵심 인용/불릿
4. FAQ QnA 4~6개
5. 요약 + CTA 링크 (중간 1회 soft, 하단 1회 hard)

## 문체
- 구어체+전문 설명 혼합
- 비유/일상 예시로 개념 설명
- 키워드 자연 반복 (남발 X)
- 광고 과다/이모지 남발 지양

## 배치
- 썸네일(키워드 문구) → 후킹 → 사진 → 섹션 → 사진 → ... → FAQ → 링크
