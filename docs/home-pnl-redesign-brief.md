# 홈 봇 수익 UI 리디자인 — 기획 브리프 (시안 단계)

## 문제 (현재 화면)

지금 구조가 국내 카피트레이딩/슈퍼메타류와 거의 동일함:

1. 큰 **평가금액** 히어로 카드  
2. **오늘 / 누적 / 건수** 3열 스트립  
3. **머스타드 세그먼트**(일별·누적)  
4. **네온 그린 막대 차트** + 빈 날 0 막대  
5. **날짜·손익·건수** 표  

→ “대시보드 복제”로 보이고, **수익 인증**이 목적인지 안 읽힘.  
부가: 헤더 거래 2건 vs 표 0건처럼 **숫자 불일치**도 신뢰 깎음.

## 목표

- 첫 화면에서 “오늘 얼마 벌었고, 그게 **실체결로 증명**된다”가 3초 안에 읽힐 것  
- Super Alpha(골드 브랜드) 고유 톤 — Toss/슈퍼메타/거래소 홈 복제 티 제거  
- 공유 CTA를 “공유”가 아니라 **수익 인증 카드**로 격상  
- 구현 전 시안 확정 (A / B 중 택1 또는 혼합)

## 버릴 패턴 / 지킬 것

| 버릴 것 | 지킬 것 |
|---------|---------|
| 평가금액이 가장 큰 숫자 | 브랜딩 골드 `#e8c36a` |
| 노란 pill 탭 2개 | 다크 베이스 + 실계좌 연동 상태 |
| 네온 막대 + 0막대 | SharePnl 시트 자산 재사용 |
| 표형 기간별 손익만 | 실데이터: dailyStats / fills / equity |

## 시안 A — 「오늘 인증」(Proof)

파일: `assets/home-pnl-concept-A-proof.png` (생성본)

- **히어로 = 오늘 손익($·%)** — 평가금액은 보조  
- 증명 스트립: TP 횟수 · 누적 · 인증카드 공유  
- 차트 = **에쿼티 스파크라인** (막대 X)  
- 하단 = **검증된 청산** 타임라인 (표 X)  
- 기간 = 언더라인 칩 `7일 / 30일 / 전체`

강점: 카피 티 가장 적음, 인증 스토리 명확.  
약점: “잔고가 보고 싶은” 유저는 한 박자 늦음.

## 시안 B — 「알파 장부」(Ledger + 인증카드)

파일: `assets/home-pnl-concept-B-ledger.png` (생성본)

- 오늘 % + $ 와 **당일 승률 링** 스플릿  
- 중앙에 **수익 인증 카드 미리보기** (공유 유도)  
- 일자 = **가로 타일 스크롤** (빈 날은 — , 0막대 금지)  
- 하단 = 청산 기록 + `MetaAPI 실체결 · 지연 n초`

강점: 공유/바이럴·신뢰 스탬프 강함.  
약점: 요소가 A보다 많아 정돈 필요.

## 확정 방향 (사용자)

- **시안 B** 채택 (`home-pnl-concept-B-v2.png`)
- 손익 숫자/% = **초록 / 빨강만** (금색 폰트 금지 — 금색은 로고·테두리·배지용)
- 헤더 로고 = **`/brand/sa-logo.png` 슈퍼알파 실로고**

## 데이터/카피 규칙 (신뢰)

- 홈 히어로 건수 = 오늘 **청산(TP/SL) 건수**와 동일 소스  
- “거래 건수” 모호어 금지 → `오늘 청산` / `오늘 진입` 분리 또는 하나만  
- 동기화 지연 초·소스 한 줄 고정 (`실체결 기준`)  
- 빈 날 차트에 0 막대 그리지 않음
