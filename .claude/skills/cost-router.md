# 비용 효율 라우팅

작업 특성에 따라 **Opus 또는 Sonnet**을 자동 선택합니다.

## 라우팅 규칙

### 🔵 Opus 사용 (복잡한 작업)
- **아키텍처 설계**: 대규모 리팩토링, 새 시스템 구축
- **알고리즘**: 복잡한 로직, 성능 최적화
- **보안/감사**: 보안 검토, 컴플라이언스
- **리스크 높음**: 실계좌, 데이터베이스 마이그레이션
- **다중 컨텍스트**: 여러 모듈 상호작용

### 🟡 Sonnet 사용 (단순한 작업)
- **기능 추가**: 알려진 패턴의 새 기능
- **버그 수정**: 명확한 문제점 수정
- **코드 스타일**: 포맷팅, 네이밍
- **문서화**: 코드 주석, README
- **테스트**: 기존 코드 테스트

## 의사결정 플로우

```
작업 요청
  ↓
복잡도 판단
  ├─ 높음 → Opus (xhigh)
  ├─ 중간 → Opus (high) 또는 Sonnet (medium)
  └─ 낮음 → Sonnet (low)
  ↓
모델 선택 후 실행
```

## 사용법

### 자동 라우팅
```
일반적인 작업 설명
```
→ cost-router가 적절한 모델 자동 선택

### 명시적 지정
```
/plan-review 복잡한 작업
/cheap-exec 단순 구현
```

## 비용 절감 효과

| 구분 | Opus (high) | Sonnet (medium) | 절감 |
|------|-----------|----------------|-----|
| 간단한 수정 | ⭕ | ✅ | 70% |
| 기능 추가 | ✅ | ⭕ | 50% |
| 대규모 리팩토링 | ✅ | ❌ | - |

**월 비용 30-50% 절감 가능**
