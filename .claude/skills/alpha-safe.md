# 슈퍼알파 안전 검증

**돈이 관련된 모든 작업**은 이 검증을 반드시 거칩니다.

## Fail-Closed (기본값: 금지)

- ✅ 명시적 승인만 진행
- ❌ 불명확하면 중단
- 🔐 비밀정보 절대 노출 금지

## 검증 대상

### 🔴 반드시 확인 (매번)
1. **실계좌 거래** (live account)
   - 거래량 한도 확인
   - 수익률 검증
   - 손실 한도 확인

2. **MetaAPI 연결** (real money)
   - API 키 권한 확인
   - 계좌 타입 (데모 vs 라이브) 검증
   - 잔고 충분성 확인

3. **강제종료 (force-close)**
   - 포지션 내역 검증
   - 손실 계산 확인
   - 타이밍 적절성 검토

### 🟡 주의 대상
- TP/SL 값 이상 (오류 방지)
- Cron 시간대 (시장 상황)
- DCA 규모 (자금 계획)

## 사용법

```
/alpha-safe 작업명
```

### 예시
```
/alpha-safe 실계좌에 1 lot 진입 (EURUSD, TP 1.1050)
```

## 검증 결과

### ✅ 통과 조건
- 모든 항목 확인 완료
- 위험도 허용 범위
- 명시적 사용자 승인

### ❌ 차단 조건
- 실계좌인데 한도 미초과 미확인
- MetaAPI 권한 불명확
- 손실액 계산 오류
- 사용자 승인 없음

## 중요
**alpha-safe는 권고가 아닌 필수 단계입니다**
- qa-gate 전에 반드시 실행
- 거래 직전 최종 확인
- 자동화 불가 (항상 사람이 확인)
