# 전략적 기획 검토

대형 작업이나 중요 결정 전에 **깊이 있는 분석**을 제공합니다.

## 검토 범위

### 1. 기획 (Architecture)
- 접근 방식 타당성
- 대안 비교
- 설계 트레이드오프

### 2. 케이스 (Use Cases)
- 정상/엣지 케이스 분석
- 동시성, 확장성 고려
- 의존성 영향도

### 3. 리스크 (Risk Assessment)
- 기술적 위험
- 성능 영향
- 데이터/보안 위협
- 롤백 전략

### 4. 비용 (Cost Analysis)
- 구현 시간 예측
- 인프라/API 비용
- 유지보수 부담

## 제약
❌ **코드는 작성하지 않습니다**
- 기획 검토만 수행
- 구현은 cheap-exec 사용

✅ **제공 결과**
- 상세 분석 문서
- 위험 등급 및 대응
- 비용 추정
- 추천 접근법

## 사용법
```
/plan-review 대형 작업 설명
```

Opus 모델의 최고 사고력으로 철저히 검토합니다.
