# QA Gate - 배포 전 검수

배포 또는 병합 전 **모든 오류를 차단**합니다.

## 검수 항목

### 1. 코드 품질
✅ ESLint / TypeScript 통과
✅ 포맷팅 (Prettier/Tailwind)
✅ 코드 복잡도 검사

### 2. 테스트
✅ 유닛 테스트 통과
✅ 통합 테스트 통과
✅ 커버리지 기준 충족

### 3. 성능
✅ 번들 크기 (Next.js)
✅ 런타임 성능
✅ 메모리 누수 없음

### 4. 보안
✅ 의존성 취약점 없음
✅ 비밀정보 노출 없음
✅ OWASP 체크

### 5. 배포 준비
✅ 데이터베이스 마이그레이션 검증
✅ 환경 변수 완성
✅ 롤백 계획 수립

## 규칙

**❌ 통과 금지 조건**
- 린트 오류 존재
- 테스트 실패
- 타입 오류
- 보안 경고

**✅ 통과 조건**
- 모든 검사 통과
- 문서화 완료
- 테스트 작성 완료

## 사용법
```
/qa-gate 파일경로
```
